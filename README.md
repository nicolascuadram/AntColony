# Ant Colony Optimization Algorithm for AI Course.

## Developer

- Nicolás Cuadra

## Requirements

- Java 8 or higher
- Java compiler (Javac)

## Compilation

To compile the proyect, you must navegate to the directory with `Main.java` file and execute the next command in the console:

```bash
javac Main.java
```

## Execution

To execute the program, use the next command in the console:

```bash
java Main <ants>
```

Where:

`<ants>` it's an argument to represent the amount of ants that will be used in the execution.

For example, an execution can be:

```bash
java Main 5000
```
